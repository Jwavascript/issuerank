## 구독 API · 서비스 워커
| 항목 | 규칙 |
|---|---|
| POST 결과 | 새 endpoint 행을 넣었으면 **201** + 본문 `{ "created": true }`(기존 `api()`가 201 본문을 돌려줘 화면이 가름 — 북마크 · 폴더 POST 201 + 본문과 같은 꼴) · 이미 있던 endpoint(키 갱신 · 같은 값)면 **204**(본문 없음, O5 그대로) · 5,000행이고 새 endpoint면 503(그대로). 그 밖 검사 순서 · 문구 · no-store · Set-Cookie 0 · 로그 그대로. 배포 직후 열려 있던 O5 화면은 201 본문을 버림 → 동작 같음 |
| 저장소 | `Store.savePushSubscription(sub, allowNew)` 반환 `boolean` → `'created' \| 'updated' \| null`(null = 상한이라 안 씀).
