- 공시·주가·본문·추가 수집·Android·배포·커밋·푸시·실제 구독자 발송은 제외. 운영 DB 마이그레이션은 별도 실제 검증 줄로 구분한다.

## 화면 변경
- 기존 화면을 유지하고 `키워드` 진입 추가. 키워드 칩·기간·순서·주요/전체·타임라인·더 보기·관심 저장/삭제·알림 토글·이 기기 연결/해제.
- 색상+이름을 같이 표시. 모바일 한 열·가로 넘침 없음. 네트워크 오류 안내 및 다시 시도, 요청 경합은 최신 결과만 표시. 계정 전환 시 개인 목록 즉시 비움.
- 추가 스크립트/스타일은 keywords.js·keywords.css에 분리. 응답을 HTML에 넣을 때 escape하고 URL http(s) 제한. 기존 아침 알림을 끄면 기기 연결도 지워짐. 개인정보처리방침에 관심 저장·선택적 계정 연결·발송 이력을 반영.
- API 계약은 ex12/openapi.yaml에 반영한다. 실제 실행에서 .data 아래 과거 검증 사본도 Vitest가 수집하는 환경 문제를 확인하여 test/**/*.test.ts로 수집 범위를 명시한다. 기존 push-ui/pwa/summary-text의 텍스트 읽기는 CRLF를 LF로 정규화해 같은 검증을 Windows에서도 수행한다. OS 사용자 정보 조회 오류는 샌드박스 밖 동일 시험으로 분리 확인한다.
