# O9a 경제 수집 표본 보완

2026-11-15 사용자 요청: investing_kr의 개별 주식 매입·매도 알림을 제외하고 일반 경제 시사 후보를 더 확보한다. O9 이후 발견한 수집 문제를 먼저 보완하며 O10~O13 전체 기능은 여기서 구현하지 않는다. 운영 폴더 `ex12/`, 근거 SPEC AC-01-1·01-2·신규01-5, PLAN D12 보충·D39. 직전 계획은 O9.

## 근거와 판단

사용자가 제공한 오늘 원자료 18건: investing_kr 임원 매매 8건 미연결, 세계3·정치3·사회1로 재분류7건, 경제 유지3건. 최종 경제5건에는 다른 수집 섹션에서 온 기사도 포함된다. 검색 실패0, 당시 남은 크레딧93. 표본에서 매매 알림이 자리를 차지한 사실은 확인했지만 검색 결과가 전부1인 원인이 이것뿐인지는 미확정이다.

핵심은 유효 경제 기사 확보다. AI에 모든 기사를 경제로 남기라고 강요하지 않고, API 요청 단계의 출처 혼합과 저장 전 정형 제목 필터를 보완한다. 사용자 요청의 규칙 수정에 해당하며 추가 호출·새 유료 서비스는 없다.

## 변경 규칙

1. **경제 top 1페이지에만** `excludedomainurl=kr.investing.com` 추가. 나머지 country=kr, language=ko, category=business, prioritydomain=top, removeduplicate=1 유지. 전체 출처 페이지 최대2는 기존 그대로라 Investing의 기업 실적·일반 경제 보도를 계속 받을 수 있다. 다른5섹션 요청과 섹션 순서도 그대로. top의 빈 결과만으로 중단하지 않고 기존 전체 출처 수집을 계속한다.
2. **모든 수집 응답에서**, source_id가 정확히 investing_kr이고 제목이 임원 직함 + 주식/보통주/자사주 + 구체적 수량·달러 금액 + 매도/매입/매수로 끝나는 정형 알림일 때만 저장 전 제외한다. 직함은 이사·수석부사장·부사장·사장·최고운영책임자·최고경영자·최고재무책임자·회장·CEO·CFO·COO, 독립된 직함 위치만 판정(이사회는 해당하지 않음).
3. source_id만 보고 Investing 전체를 거르지 않는다. 기업 실적·매출·금리·경제 전망·자사주 매입 결정 및 다른 출처 보도는 유지한다. 기사 본문을 요청하거나 읽지 않는다.
4. 제외는 AI 입력 전 미래 수집분에 적용한다. 제외 응답 건수를 섹션별 `filtered`로 돌려주고 CLI에 0이 아닐 때만 `· 매매 알림 제외 응답 N건`을 덧붙인다. 요청 응답에 나타난 건수로 중복 응답도 각각 세며 저장 기사 수와 혼동하지 않는다. DB 스키마 변경 없음.
5. 제외 후 해당 섹션에 저장 가능한 기사가0이면 failed(`매매 알림 제외 후 기사 0건`), AC-01-2에 따라 기존 기사 보존. 요청 일부 실패도 기존과 같이 그 섹션 전체 failed이며 이전 자료 보존.

## 범위·외부 근거

- 호출 최대: collect18회, group36회 기존 한도 유지. --pages 허용0~2 그대로. 추가 보충 페이지·재시도0, OpenAI 모델·프롬프트·요약·순위식·API 계약·화면 변경0. 기존 저장 기사·이슈·요약·북마크 삭제나 daily 수동 실행 없음.
- 새 패키지·키·DB 변경0. 실제 API 확인에는 ex12/.env의 NEWSDATA_API_KEY만 필요하며 현재 로컬에 없음. DB 확인은 DATABASE_URL이 필요하지만 이번 로컬 검증에서는 사용하지 않는다.
- [NewsData 공식 latest 문서](https://newsdata.io/documentation/latest-news-api), 2026-11-15 확인: excludedomainurl은 Free/Basic 최대5개 도메인을 제외할 수 있음. 경제 top에서만 해당 필터를 사용한다. 실제 계정 요청 성공과 표본 개선 효과는 아직 확인 전이다.
