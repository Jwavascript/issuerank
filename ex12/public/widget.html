이슈랭크

홈 화면 위젯

휴대폰 버전에 따라 메뉴 이름이 조금 다를 수 있습니다.

앱으로 설치

  • Android(Chrome): Chrome으로 이슈랭크(https://issuerank-kappa.vercel.app)를 열고 오른쪽 위 설치 아이콘(또는 맨 아래 앱 설치)을 누른 뒤 설치를 누릅니다. 보이지 않으면 더보기(⋮)에서 앱 설치 또는 홈 화면에 추가를 고릅니다. 카카오톡 등 앱 안 브라우저에는 설치 메뉴가 없을 수 있으니 Chrome으로 여세요.
  • iPhone(Safari): Safari로 이슈랭크를 열고 공유(□↑) › 홈 화면에 추가 › 추가를 누릅니다. iOS 16.4 이상은 Chrome 등 다른 브라우저의 공유 메뉴에서도 됩니다. 홈 화면 앱은 Safari와 로그인이 따로라 앱에서 다시 로그인해야 할 수 있습니다.

iPhone

  1. App Store에서 Scriptable(무료, iOS 15.5 이상)을 설치합니다.
  2. 이 페이지의 스크립트 복사를 누릅니다.
  3. Scriptable을 열고 오른쪽 위 + → 빈 화면을 길게 눌러 붙여넣기 → 위쪽 제목을 이슈랭크로 바꾸고 완료. ▶를 누르면 중간 크기 미리보기가 보입니다.
  4. 홈 화면 빈 곳을 길게 눌러 편집 › 위젯 추가 → Scriptable → 크기(작게 3줄 · 중간 5줄 · 크게 10줄) → 위젯 추가.
  5. 위젯을 길게 눌러 위젯 편집 → Script에서 이슈랭크를 고릅니다.
  6. 중간 · 큰 위젯은 줄을, 작은 위젯은 아무 데나 누르면 Safari에서 이슈랭크가 열립니다(Scriptable이 잠깐 보일 수 있음). 하단 시각이 오늘이 아니면 아직 갱신 전입니다(매일 새벽 갱신). 새 버전이 나오면 같은 방법으로 내용을 바꿔 붙여넣습니다.

Android
